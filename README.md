## Python Mini Projects

Welcome to my little corner of Python.

This repository is basically where I dump every mini project I build while learning Python. Some are super simple, some made my brain crash for an hour, and some taught me that one tiny semicolon isn't always the problem (looking at you... logic).

I'm not trying to make everything perfect here.

I'm trying to get better.

Every folder is a new concept, a new challenge, or just me experimenting with something I learned that day. So if you scroll from the first project to the latest one, you'll literally see my progress in code.

## What you'll find here

* Beginner Python projects
* Practice programs
* Small coding challenges
* Random experiments
* Lots of learning

## Why this repo?

Because learning by watching tutorials only gets you so far.

The real learning starts when you open VS Code, stare at the screen for 20 minutes, break your code five times, fix it on the sixth try, and finally see it work.

That's exactly what this repository is.

If you're learning Python too, feel free to look around. Maybe you'll learn something from my projects, maybe you'll find a better way to solve them. Either way... keep coding.

See you in the next commit.
